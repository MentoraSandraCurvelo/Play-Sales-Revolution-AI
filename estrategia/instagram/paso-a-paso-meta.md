# Paso a paso: conectar Meta (Facebook, Instagram, WhatsApp y anuncios)
Hazlo desde el computador. Tiempo aproximado: 30 a 45 minutos. Los nombres de los menús de Meta cambian seguido: si algo no aparece igual, mándale captura a Isaía.

## Parte 1. Crear la página de Facebook (5 min)
1. Entra a facebook.com con tu cuenta personal.
2. Menú (los 9 puntos o "Menú") → Páginas → Crear nueva página.
3. Nombre: Sandra Curvelo · IAM™. Categoría: Consultor de negocios (o Servicio de educación). Biografía: la misma de Instagram.
4. Sube la misma foto de perfil de Instagram y una portada.

## Parte 2. Vincular Instagram con la página (5 min)
1. Dentro de la página: Configuración → Cuentas vinculadas → Instagram → Conectar cuenta.
2. Entra con @sandracurvelo_iam.
3. Cuando pregunte por los mensajes de Instagram, dale Permitir.

## Parte 3. Crear el portafolio comercial (10 min)
1. Entra a business.facebook.com → Crear portafolio comercial.
2. Nombre: IAM. Tu nombre y tu correo de trabajo.
3. Configuración (engranaje) → Cuentas → Páginas → Agregar → elige tu página.
4. Cuentas → Cuentas de Instagram → Agregar → @sandracurvelo_iam.
5. WhatsApp: si usas WhatsApp Business en el celular, abre la app → Herramientas para la empresa → Facebook e Instagram → conecta la página.

## Parte 4. Crear la cuenta publicitaria (10 min)
1. Configuración → Cuentas → Cuentas publicitarias → Agregar → Crear una cuenta publicitaria nueva.
2. Nombre: IAM Anuncios. Zona horaria: Bogotá. Moneda: peso colombiano (después no se puede cambiar).
3. Asígnate con control total.
4. Facturación y pagos → agrega tu tarjeta. Recomendado: pon un límite de gasto de la cuenta para estar tranquila.

## Parte 5. Darle acceso a Isaía (10 min)
1. Configuración → Usuarios → Usuarios del sistema → Agregar → nombre: Isaía (rol administrador).
2. Asignar activos → marca la página, Instagram y la cuenta publicitaria, con control total.
3. Generar token → app "Isaía IAM™" → caducidad: nunca → marca estos permisos: ads_management, ads_read, business_management, pages_show_list, pages_read_engagement, pages_manage_metadata, instagram_basic, instagram_manage_comments, instagram_manage_messages, instagram_content_publish.
4. Si la app no muestra los permisos de anuncios: developers.facebook.com → tu app → Agregar producto → API de marketing.
5. Copia el token y NO lo pegues en el chat. Avísale a Isaía: te abre un formulario seguro donde lo pegas.
